# NAFS — передача проекта (13.11.2026)

В архиве — исходный Next.js-проект с Telegram Mini App, серверной Telegram-авторизацией, разделом `/admin`, статистикой Telegram-посещений и 800 локализованными мотивационными сообщениями: по 400 для обычного и исламского режима (ru/en/tr/ar).

## Вход и администратор

- Telegram-вход: `POST /api/auth/telegram`, проверка подписанного Telegram `initData` на сервере, серверная сессия в HttpOnly-cookie. Подтверждение владельца — через запись подтверждённого Telegram ID `6123609704`, а не через пользовательский параметр.
- Панель: `/admin`; данные посещений: `GET /api/admin/visitors` (только владельцу). Показывает пользователей, количество успешных входов, первый/последний вход, активных за 24 ч. Личные записи, SOS и задачи в статистику не попадают.
- Для работающего подключения необходимы действующий Telegram-бот и BotFather Mini App URL, Supabase, серверные переменные из `.env.example`, миграции `supabase/migrations/001_...`–`006_owner_visits.sql` и публичное HTTPS-размещение. Не передавайте токены в чат или git.
- Старый статический предпросмотр на `chatgpt.site` не предоставляет настоящую серверную авторизацию: для тестирования входа нужен полноценный серверный деплой.

## Контент

`content/motivation.json`: 800 записей, из них 400 `faith=false` и 400 `faith=true`; у каждой есть ru/en/tr/ar. Исламские тексты являются авторскими напоминаниями без аятов и выдуманных ссылок на хадисы. Варианты строятся на комбинациях вводной фразы и практического действия; требуется редакторская вычитка перед публичным выпуском.

## Проверка в текущем сеансе

Статическая проверка JSON: 800 записей, по 400 на каждый режим, в русском тексте каждого режима 400 разных строк. Попытка `npm run typecheck` не завершилась: директория `node_modules` содержит неполную установку, отсутствуют типы. `npm ci --prefer-offline` превысила лимит времени. Поэтому успешную сборку, тесты и работающий реальный Telegram-вход в этом сеансе **не подтверждаем**. Запустите `npm ci`, `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` в среде с доступом к npm. Архив содержит исходники, но не зависимости и не секреты.
