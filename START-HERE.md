# NAFS: как посмотреть и запустить

## Проверить с телефона

Откройте в браузере https://nafs-private-check-werllap.placidmarshmallow1.chatgpt.site под тем же аккаунтом ChatGPT. Это закрытый гостевой предпросмотр. В нём можно создавать задачи, события, привычки и марафоны, менять темы, сохранять мотивацию. Данные хранятся в этом браузере по этому адресу.

Вход Telegram, синхронизация и рассылка требуют отдельного сервера. Не указывайте закрытую гостевую ссылку в BotFather как готовый backend. `localhost` на iPhone означает сам телефон, поэтому адрес с компьютера там не откроется.

## Запустить исходники

Нужен Node.js24 или новее:

```sh
npm ci
cp .env.example .env.local
npm run dev
```

На том же компьютере откройте http://localhost:3000. Без ключей работает гостевой режим. Для production-проверки: `npm run build && npm run preview:offline && npm start`.

## Подключить Telegram

1. Создайте бота через проверенного @BotFather → /newbot. Сохраните токен только в серверном TELEGRAM_BOT_TOKEN.
2. Создайте Supabase, примените миграции001–005 по порядку, выполните `npm run seed` с серверными переменными окружения.
3. После отдельного разрешения на размещение разверните Next.js на HTTPS-хостинге. Задайте APP_URL и параметры Supabase из .env.example.
4. В BotFather настройте Main Mini App и /setmenubutton на фактический HTTPS-адрес. Иконка: public/icon-512.png.
5. Проверьте вход и изоляцию двумя реальными Telegram-аккаунтами, экспорт/удаление и поведение на iPhone/Android.

Подробно: docs/telegram/README.md и DEPLOYMENT.md.

## Админская рассылка

Укажите UUID разрешённых аккаунтов NAFS в NAFS_ADMIN_USER_IDS и войдите на /admin. Создайте черновик, проверьте текст и аудиторию, подтвердите отправку. Получатели должны открыть чат бота и включить сообщения в профиле. Очередь обрабатывается вручную пакетами или защищённым worker через планировщик с CRON_SECRET. Ни одной реальной рассылки при разработке не отправлено. Инструкция: docs/BROADCAST.md.
